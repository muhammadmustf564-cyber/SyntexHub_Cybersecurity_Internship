# Task 1 — Cybersecurity Internship

This folder contains the two projects completed as part of **Task 1** of my SyntecxHub Cybersecurity Internship.

## 📁 Projects

### 1. TCP Port Scanner
A Python-based TCP port scanner that checks ports on an authorized host and identifies open and closed ports.

**Technologies:** Python, Socket Programming, TCP, Concurrency

### 2. Password Manager
A local Python-based password manager that securely stores credentials using encrypted storage.

**Technologies:** Python, Cryptography, JSON, Encryption

## 🎯 Learning Outcomes

Through these projects, I practiced:

- Python programming
- TCP and socket concepts
- Port scanning
- File and JSON handling
- Encryption and secure credential storage
- Exception handling
- Basic cybersecurity concepts
